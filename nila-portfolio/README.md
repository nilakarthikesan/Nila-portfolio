# Portfolio starter application

An earlier Next.js starter retained inside the portfolio repository. It was initialized with `create-next-app`. The standalone portfolio is at [`../index.html`](../index.html); the root Next.js implementation is in `../src/`.

From this directory:

```bash
npm install
npm run dev
```

The page and root layout are in `src/app/`. Scripts and dependencies are defined in this directory's `package.json`.
